Generated by reading the controllers on 14.10.2026. **Source code wins** over this file; when they
disagree, fix this file in the same change. Base URL: `http://localhost:8888`. Swagger UI
(springdoc) is available on the running backend.

Entities are returned directly unless stated otherwise — their JSON shape is the entity's fields
(see `model/entity/**`).

- Endpoint: `/ws-console` (plain WebSocket and SockJS), allowed origins `*`.
